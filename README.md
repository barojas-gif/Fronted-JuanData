# JuanData - Frontend

Frontend del proyecto **JuanData**, desarrollado con **Angular 19.2.0**.

Este proyecto contiene la interfaz web de JuanData y se encuentra alojado en GitHub.

**Repositorio oficial:**  
https://github.com/barojas-gif/Fronted-JuanData.git
