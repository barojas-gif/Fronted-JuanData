# JuanData - Frontend

Aplicación web frontend del proyecto **JuanData**, desarrollada con **Angular 19.2.0**.

Este proyecto contiene la interfaz de usuario y la lógica frontend para la plataforma JuanData.

---

## 📋 Requisitos previos

Antes de instalar el proyecto, asegúrate de tener instalado:

- **Git**
- **Node.js**
- **npm**
- **Angular CLI**

Puedes comprobar las versiones instaladas con:

```bash
git --version
node --version
npm --version
ng version
